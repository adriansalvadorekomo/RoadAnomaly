# Learning records

This directory holds `Profile: learning` records written by the template and
the specialized notebooks. Copy [`../0000-template.md`](../0000-template.md),
number the record in order, and keep the `Profile: learning` line.

A learning record is reproducible, but it is **not evidence**:

- It is not listed in the official [`../README.md`](../README.md) index.
- It cannot support a number in the repository README, the report or a
  presentation.
- It cannot select, tune or promote a model.

If a learning result is worth publishing, create an official config under
`configs/` and rerun it with `profile: official`. Only the official record can be
cited. Official records live one directory up, not here.
